# 20. 버전 업데이트 로드맵 템플릿 (Version Update Framework)

## 가정 (Assumption)
- 본 문서는 **실제 2.0 이후 콘텐츠 기획이 아니며**, 향후 모든 버전 업데이트가 따라야 할 재사용 가능한 틀(템플릿)만 정의한다.
- 버전 주기는 약 6주 1사이클로 가정(14번 문서 배너 로테이션 주기와 정합).
- 버전 번호 체계는 "X.Y" 형태(X=대형 지역 확장, Y=소형 패치/이벤트)로 가정.

## 1. 버전 업데이트 표준 구성 요소
버전 X.0(대형 업데이트, 신규 대륙/지역 오픈)마다 아래 구성 요소를 **반드시** 포함해야 한다.

| 구성 요소 | 표준 수량 | 비고 |
|---|---|---|
| 신규 지역(대륙/군도) | 1곳 | 08번 문서와 동일한 항목(지형/랜드마크/서브지역 3~5개/기후) 작성 필요 |
| 신규 캐릭터 | N명 (표준 4~6명) | 13번 문서와 동일 포맷(역할/속성/무기/배경/디자인 키워드) |
| 신규 스토리 챕터 | 1개 챕터(프롤로그 없이 장 단위) | 11번 문서와 동일 포맷(챕터별 목표/보스) |
| 신규 던전 유형 또는 변형 | 기존 4종 분류(09번) 내 신규 변형 1개 이상 | 완전히 새로운 분류 신설은 지양(학습비용), 기존 분류 심화 우선 |
| 신규 공명 융합 체인(선택) | 0~1개 | 기존 7속성 체계(02번) 내에서 조합, 신규 속성 추가는 원칙적으로 지양(밸런스/아이콘 체계 영향 큼 — 추가 시 별도 전체 재검토 필요) |
| 배너 로테이션 계획 | 신규 ★5 캐릭터 기준 순차 픽업 | 14번 문서 배너 운영 원칙 준수 |
| 경제 재화 조정 검토 | 필수 | 16번 문서 인플레이션 방지 원칙에 따라 신규 소모처 계획 동반 |

## 2. 버전 기획 체크리스트 (신규 버전 착수 시 순서대로 확인)
1. [ ] 신규 지역이 기존 세계 지리(02번 5장, 08번 4장 "확장 연결점")와 서사적으로 자연스럽게 이어지는가?
2. [ ] 신규 캐릭터의 공명속성/무기 분포가 기존 로스터(13번 2장)와 겹치지 않고 다양성을 확장하는가?
3. [ ] 신규 스토리 챕터가 메인 시놉시스(11번)의 오픈 엔딩(흩어진 코어 파편 탐색)과 연결되는가?
4. [ ] 신규 던전이 09번 문서의 보스전 템플릿(3페이즈+균열 상태)을 준수하는가?
5. [ ] 신규 콘텐츠 투입 시 무과금/과금 밸런스 원칙(16번 3장)이 깨지지 않는가?
6. [ ] 기술적으로 19번 문서의 "지역=독립 번들" 구조를 그대로 확장하는 방식인가(엔진 구조 변경 불필요 여부 확인)?

## 3. 버전 사이클 표준 일정 (템플릿, 예시 수치)
| 주차 | 활동 |
|---|---|
| 1주차 | 신규 캐릭터 배너 A 출시 + 소형 이벤트 |
| 2~3주차 | 이벤트 스토리 진행형 콘텐츠 오픈 |
| 4주차 | 신규 캐릭터 배너 B(또는 리런 배너) 전환 |
| 5~6주차 | 다음 버전 예고 + 서버 점검 대형 업데이트 준비 |

## 4. 버전 넘버링 규칙
- X.0: 신규 지역 오픈(대형)
- X.1, X.2: 소형 이벤트/캐릭터 배너 패치(신규 지역 없음)
- 예: 1.0(세라티아 런칭) → 1.1(소형 이벤트) → 1.2(소형 이벤트) → 2.0(신규 대륙 오픈)

## 5. 본 템플릿의 사용 범위 명시
- 이 문서는 **틀(프레임워크)만 제공**하며, 실제 2.0의 지역명/캐릭터/스토리 내용은 포함하지 않는다. 향후 버전 기획 시 본 템플릿의 표와 체크리스트를 복사하여 실제 콘텐츠 기획 문서를 별도로 작성한다.
