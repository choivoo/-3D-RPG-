# 체크포인트 1 (문서 01~05 완료 후)

## 확정된 핵심 용어/설정 요약
- **게임명**: 프리즘폴 연대기 (Prismfall Chronicle)
- **세계명**: 루메브리스 (Lumevris)
- **신화**: 프리마 루스 → 위버 7명 → 대붕락(프리즘폴) → 프리즘 코어 7개 파편 → 루멘 입자 → 공명자
- **파워 시스템명**: 공명(Resonance), 속성 상호작용 = 공명 융합(Resonance Fusion)
- **7대 공명속성**: 염광/수류/지맥/뇌섬/빙결/풍영/성흔 (각 색상·철학·대응 위버 확정)
- **무기 타입 5종**: 장검/쌍검/대검/활/영창서
- **스탯 체계**: HP/ATK/DEF/공명력(RES)/치확/치피/원기회복률/융합숙련(FM)
- **레어도**: ★3(정예)/★4(상급)/★5(전설), 테두리 컬러 확정
- **1.0 지역**: 세라티아(대륙), 서브지역 5곳(아르모나 항구/벨루하 숲/카르나 고원/이스나 유적/팔로스만 절벽)
- **아트 스타일**: 서브컬처 셀셰이딩, 7.5등신, 지역별 주조색+보조색 2개 제한

## 정합성 확인
- 02번의 7속성 컬러코드가 03번 아트 문서와 05번 캐릭터 문서에서 동일하게 재사용됨 — 모순 없음.
- 05번 레어도 테두리 컬러가 03번 UI 가이드에서 "05번과 동일" 참조로 연결됨 — 정합.
- 무기 타입 크기 규정(03번)과 무기 타입 목록(05번)이 5종으로 일치.

특이 모순 없음. 다음 문서군(06~10)에서 전투 시스템, 이동 디자인, 지역 상세, 던전, NPC/팩션을 위 용어 기준으로 확장한다.
