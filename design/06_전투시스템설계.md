# 06. 전투 시스템 설계 (Combat System)

## 가정 (Assumption)
- 파티 규모는 4인 편성(동시 필드 1인 조작 + 3인 대기)으로 확정, 장르 표준 관행을 따른다.
- 공명 융합 체인(3속성 연계) 수치는 초기 밸런싱 가안이며, 실제 수치 튜닝은 QA 단계에서 조정 전제.

## 1. 기본 콤보 구조
- 지상 일반공격: 무기별 최대 5단 콤보(예: 장검 1~5타), 마지막 타에 소폭 넉백/이펙트 강화.
- 강공격(차지): 버튼 홀드 시 발동, 일반공격 대비 1.8배 배율, 시전 중 이동 불가.
- 공중 콤보: 점프/등반 캔슬 후 낙하공격 가능, 낙하 높이에 비례한 피해 보너스(최대 2.2배, 4단계 높이 구간).
- 회피(닷지): 무적 프레임 0.3초, 회피 직후 0.5초 내 반격 시 "완벽 회피" 보너스 피해 +20%.

## 2. 스킬 / 궁극기 구조
| 스킬 유형 | 명칭 | 자원 | 쿨다운(예시) | 설명 |
|---|---|---|---|---|
| 필드 스킬 | 공명기(Resonance Skill) | 즉시 재사용 게이지(자동 충전 6초) | 6~12초 | 캐릭터별 고유 단발/지속 스킬 |
| 궁극기 | 각성기(Awakening Art) | 원기(Energy) 0~100, 전투 중 공격/피격 시 충전 | 자원 충전형(쿨다운 없음) | 강력한 광역/버스트, 파티 전체 버프 겸하는 경우多 |
| 패시브 | 각인(Engraving) | - | - | 상시 발동형 특성 2~3개 |

## 3. 공명 융합(Resonance Fusion) 상호작용 표
2속성 즉발 반응(기본형) + 3속성 연쇄 반응(차별화 시스템, "융합 체인")으로 이원화한다.

### 3.1 2속성 즉발 반응 (기본형, 접촉 순서 무관)
| 조합 | 반응명 | 효과 |
|---|---|---|
| 염광 + 수류 | 증발(蒸發) | 즉발 피해량 1.5배, 증기 지형 생성(시야 방해) |
| 염광 + 빙결 | 융해(融解) | 즉발 피해량 1.5배, 대상 방어력 15% 감소(6초) |
| 염광 + 풍영 | 확산(擴散) | 염광 피해를 반경 4m로 확산 |
| 수류 + 뇌섬 | 감전(感電) | 지속 피해(DoT) 4초간 매초 발동, 물웅덩이 전체 감전 |
| 수류 + 빙결 | 동결(凍結) | 대상 완전 행동불능 2.5초 |
| 지맥 + 뇌섬 | 결정화(結晶化) | 실드 생성(피격 시 대신 소모), 실드량은 지맥 캐릭터 DEF 비례 |
| 풍영 + 빙결 | 냉각확산(冷却擴散) | 빙결 효과를 반경 4m로 확산 |
| 성흔 + 그 외 모든 속성 | 공명 증폭(共鳴增幅) | 해당 속성 스킬 피해량 25% 증가(8초), 대신 즉발 피해 없음 |

### 3.2 3속성 연쇄 반응 — "융합 체인" (차별화 시스템, 차별점 1)
정해진 순서로 3개 속성을 8초 이내에 적중시키면 발동하는 대형 반응. 순서가 다르면 발동하지 않고 2속성 반응만 개별 적용된다.

| 체인 순서 | 체인명 | 효과 |
|---|---|---|
| 염광 → 수류 → 뇌섬 | 폭발성 증기 체인 | 광역 피해(반경 6m) + 4초 지속 감전 지형 생성 |
| 빙결 → 지맥 → 염광 | 파쇄 체인 | 대상 방어구 파괴(방어력 40% 감소, 10초) + 넉다운 |
| 풍영 → 성흔 → 아무 속성 | 가속 체인 | 파티 전원 이동속도+공격속도 15% 증가(10초) |

## 4. 파티 스왑 메커니즘
- 4인 파티 중 1인만 필드에서 직접 조작, 나머지 3인은 대기 상태에서 자동 회복(체력 제외, 자원만).
- 스왑 쿨다운: 1.5초(스왑 남용 방지), 스왑 직후 0.2초간 해당 캐릭터 피해 무적(스왑 안전창).
- "스왑 연계기(Swap Art)": 스왑 직후 3초 이내 스킬 사용 시 소폭 추가 피해(+10%)를 주어 스왑 타이밍 플레이를 유도.
- 파티 구성 규칙: 4개 역할군(딜러/서포터/탱커/유틸) 중 최소 2종 이상 포함 시 필드 보너스(전체 방어력 +5%) 적용 — 극단적 딜러 4인 조합을 완전 배제하지 않으면서 균형 조합을 유도.
