# 04. 핵심 게임 루프 (Core Gameplay Loop)

## 가정 (Assumption)
- 세션당 평균 플레이 시간 목표(모바일 특성 반영)를 15~25분으로 임의 설정했다.
- 일일/주간 리셋 시각은 한국 서비스 기준 매일 05:00, 주간 리셋은 월요일 05:00으로 가정(글로벌 서버 분리는 본 문서 범위 밖).

## 1. 거시 루프: 탐험 → 전투 → 수집 → 육성 → 재탐험

```
[탐험] 오픈월드 이동/등반/활공으로 신규 지형 발견
   ↓
[전투] 필드 몬스터·미니던전 조우, 공명 융합 콤보 실행
   ↓
[수집] 전투/탐험 보상으로 재료·재화·장비 획득
   ↓
[육성] 캐릭터 레벨업·무기 강화·성물 장착 (상세 15번 문서)
   ↓
[재탐험] 강화된 전력으로 이전에 막혔던 구역(고레벨 등반 지형, 강적) 재도전
   → 루프 반복, 매 사이클마다 접근 가능 지역이 확장되는 구조
```

이 순환은 "실력/전력 상승 → 이전에 못 가던 곳에 감" 이라는 오픈월드 장르의 핵심 동기 구조를 따른다.

## 2. 세션당 플레이 타임 설계
| 세션 유형 | 목표 시간 | 구성 |
|---|---|---|
| 짧은 세션(출퇴근/틈새) | 5~8분 | 일일 임무 1~2개 + 자원 파밍 1회전 |
| 표준 세션 | 15~25분 | 탐험 1개 서브구역 + 전투 3~5회 + 육성 정리 |
| 몰입 세션(주말 등) | 40분 이상 | 메인 스토리 챕터 진행 또는 던전 공략 |

- 로딩 목표: 최초 진입 8초 이내(WebGL 스트리밍 로드, 상세 `19_기술아키텍처계획.md`), 씬 전환 3초 이내.

## 3. 일일 루프 (Daily Loop)
| 항목 | 내용 | 소요시간(목표) |
|---|---|---|
| 일일 위탁 임무 (탐사 의뢰) | 4개 슬롯, 완료 시 경험치+소액 재화 | 3~5분 |
| 체력(스태미나형 자원) 소모 던전 | "메아리 회랑" 일일 파밍 던전, 1일 체력 120 기준 약 6회 입장 | 8~12분 |
| 상점 갱신 확인 | 명성 상점 일일 라인업 구매 | 1분 |
| 일일 로그인 보상 | 자동 수령 | - |

## 4. 주간 루프 (Weekly Loop)
| 항목 | 내용 |
|---|---|
| 주간 보스전 3종 (속성별 "코어 수호자") | 주 3회 도전 티켓 제한, 캐릭터 승급재료 드롭 |
| 심층 탐사 던전 ("심연 회랑") | 주간 순위 보상형, 파티 조합 최적화 유도 |
| 명성 주간 임무(월드 퀘스트 묶음) | 세력 호감도 상승 재화 지급 |
| 배틀패스("탐사 기록서") 주간 경험치 상한 | 주 사용자당 상한선으로 F2P/과금 유저 시간 투자 격차 완화 |

## 5. 루프 간 상호 강화 설계 원칙
1. **탐험 보상은 반드시 전투/육성에 즉시 재투입 가능해야 한다** — 발견 즉시 쓸모없는 수집품 지양(상세 밀도는 `07_오픈월드이동디자인.md`).
2. **일일 루프는 15분 내 완결**, 주간 루프는 선택적 심화 콘텐츠로 분리하여 라이트 유저 이탈 방지.
3. **재탐험 동기 부여**: 전력이 일정 임계치를 넘으면 이전 지역에 "재방문 전용 보상"(고유 스킨 재료, 숨겨진 서브 스토리)이 개방되는 구조를 1.0부터 적용.

## 6. 루프 KPI 가정치 (밸런싱 기준점)
| 지표 | 목표값 |
|---|---|
| D1 리텐션 | 45% 이상 |
| D7 리텐션 | 20% 이상 |
| 일일 평균 세션 수 | 2.5회 |
| 일일 평균 플레이타임 | 35~50분 |
