# 09. 던전 & 퍼즐 가이드라인 (Dungeon & Puzzle Guidelines)

## 가정 (Assumption)
- 던전 타입 분류 기준(4종)은 콘텐츠 파이프라인 관리 편의를 위해 본 문서에서 최초 정의.
- 보스전 페이즈 수(3페이즈 표준)는 임의 기준치.

## 1. 던전 타입 분류
| 타입 | 명칭 | 목적 | 재도전 주기 |
|---|---|---|---|
| A. 전투 특화 | 메아리 회랑 (Echo Corridor) | 일일 파밍(캐릭터 육성 재료) | 매일 |
| B. 퍼즐 특화 | 공명 신전 (Resonance Shrine) | 필드 퍼즐+소형 전투, 탐사 점수/영구 보상 | 1회성(영구 클리어) |
| C. 도전 특화 | 심연 회랑 (Abyss Corridor) | 파티 조합 최적화 요구 고난도 전투 | 매주 |
| D. 스토리 특화 | 봉인 유적 (Sealed Relic) | 메인/서브 퀘스트 전용 던전, 서사 연출 중심 | 퀘스트 진행 중 1회 |

## 2. 퍼즐 메커니즘 원칙
1. **속성 활용 원칙**: 모든 필드 퍼즐은 반드시 하나 이상의 공명속성 활용을 요구해야 한다(예: 수류로 물길 형성, 지맥으로 발판 생성, 빙결로 이동경로 동결).
2. **비강제 힌트 원칙**: 퍼즐 진입 후 90초 경과 시 자동으로 약한 시각 힌트(반짝임) 노출 — 막힘으로 인한 이탈 방지.
3. **재사용 가능한 문법**: 신규 퍼즐 유형은 최소 2개 던전에서 재사용되어야 학습 비용이 회수된다(1회성 전용 기믹 지양).
4. **난이도 곡선**: 서브지역 최초 공명 신전은 튜토리얼형(단일 기믹), 이후 신전은 2개 이상 기믹 조합형으로 설계.

### 2.1 대표 퍼즐 패턴 (1.0 기준 3종)
| 패턴명 | 사용 속성 | 설명 |
|---|---|---|
| 물길 개통 | 수류 | 물류를 이용해 수차/문 개방 |
| 결정 발판 | 지맥 | 벽면에 지맥 스킬로 임시 발판 생성 후 등반 |
| 서리다리 | 빙결 | 흐르는 물을 순간 동결시켜 임시 통로 생성 |

## 3. 보스전 설계 템플릿
모든 1.0 보스(주간 보스 "코어 수호자" 3종 포함)는 아래 공통 템플릿을 따른다.

### 3.1 표준 3페이즈 구조
| 페이즈 | 체력 구간 | 설계 목적 |
|---|---|---|
| 페이즈 1 | 100%~70% | 기본 패턴 학습(공격 텔레그래프 인지) |
| 페이즈 2 | 70%~30% | 공명 융합 유도 기믹 등장(특정 속성 약점 노출 구간, "균열 상태") |
| 페이즈 3 | 30%~0% | 광역 압박 패턴 + 처치 타이밍(엔라지) 30초 도입 |

### 3.2 약점 시스템 ("균열 상태, Fracture")
- 보스는 특정 공명속성 공격을 일정량 누적하면 "균열 상태"에 돌입, 5초간 방어력 -50% + 강제 경직.
- 균열 게이지는 보스별로 상이한 속성 조합을 요구하여 파티 편성 다양화를 유도(예: 코어 수호자 A는 빙결→염광 조합 시 균열 게이지 2배 축적).

### 3.3 보스전 공통 규칙
- 보스전 진입 전 파티 편성 확인 화면 제공(권장 속성 아이콘 표시).
- 전투 시간 목표: 표준 3~5분(6번 문서 기준과 동일), 10분 초과 시 밸런스 재검토 대상으로 플래그.
