# 07. 오픈월드 이동 디자인 (Open World Movement)

## 가정 (Assumption)
- 스태미나 총량/소모율은 임의 초기값이며 밸런싱 단계에서 조정 전제.
- 활공 수단은 아이템 형태(장비형, 퀘스트 보상으로 프롤로그 중 획득)로 가정한다.

## 1. 이동 기믹 목록 (오리지널 명칭)

### 1.1 공명 등반 (Resonance Climb)
표면에 손을 짚으면 루멘 입자가 반응해 미끄럼을 방지해주는 등반 방식. 수직 절벽/암벽을 스태미나 소모하며 등반.
- 소모: 초당 스태미나 8 소모
- 예외: 비/폭풍 기상 시 소모율 +50%(지역 기믹, `08_메인지역상세설계.md`의 팔로스만 절벽과 연동)

### 1.2 천영날개 (Cheonyeong Wing) — 활공
등에 장착하는 활공 장비. 절벽/고지대에서 발동, 체공 중 스태미나 소모.
- 최대 체공 시간: 45초(기본), 성물/특성으로 최대 60초까지 연장 가능
- 상승기류 구역("풍주, Wind Pillar")에서는 스태미나 소모 없이 상승 가능 — 탐험 유도 장치

### 1.3 수영 / 잠영
일반 수영은 스태미나 무제한(수류 친화 지역 설계 의도), 잠영(수중 탐사)은 별도 산소 게이지(최대 30초) 사용.

### 1.4 지상 이동 보조 — 활공 곤돌라 "풍영삭도"
일부 서브지역(카르나 고원)에 설치된 고정 노선형 활공 장치, 스태미나 소모 없이 거점 간 고속 이동.

## 2. 스태미나 시스템
| 항목 | 수치 |
|---|---|
| 기본 스태미나 총량 | 100 (탐사 성장 요소로 최대 240까지 확장 가능, 성장재료는 "풍영의 결정") |
| 초당 자연 회복(비소모 상태) | 20/초 (2.5초 지연 후 회복 시작) |
| 등반 소모 | 8/초 |
| 활공 소모 | 4/초 |
| 전력질주 소모 | 6/초 |
| 전투 중 | 스태미나 소모 없음(전투 자원은 별도 궁극기 원기 게이지 사용) |

## 3. 탐험 보상 밀도 가이드
오픈월드 보상은 "즉시 쓸모 있음" 원칙(04번 문서 5장)을 따라 아래 밀도로 배치한다.

| 반경 | 배치 요소 | 밀도(1km² 기준) |
|---|---|---|
| 근거리(시야 내 유인) | 소형 채집물, 미니 퍼즐(공명 문양 맞추기) | 12~18개 |
| 중거리(랜드마크 유인) | 미니 던전 입구, 야외 정예 몬스터 | 3~5개 |
| 원거리(스카이라인 유인) | 랜드마크 구조물(등반 목적지), 전경 포인트(사진/도감 등록) | 1~2개 |
| 히든 | 지형 퍼즐 해결형 보물상자, 숨겨진 서브 스토리 NPC | 1~2개 |

- 설계 원칙: 플레이어가 어느 방향을 보아도 "다음 목적지가 하나는 시야에 걸려야 한다"(랜드마크 시인성 규칙, 최소 2개 랜드마크가 항상 스카이라인에 존재).
- 보상 상한 규칙: 서브지역당 완전탐사 시 지급되는 "탐사 점수"가 캐릭터/스태미나 성장 재화로 직결되어 탐험이 육성 루프와 즉시 연결된다.

## 4. 이동 기믹과 공명속성의 연계
- 풍영 속성 캐릭터의 필드 스킬은 활공 중 재사용 대기시간 없이 체공시간을 8초 연장(속성-이동 시너지, 파티 구성 다양화 유도).
- 지맥 속성 캐릭터는 등반 중 낙하 피해 완전 무효화 패시브를 가진 경우가 많다(캐릭터 설계 지침, `13_1.0캐릭터로스터.md`에서 구체화).
