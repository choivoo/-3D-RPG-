# 01. 프로젝트 헌장 (Project Charter)

## 가정 (Assumption)
- 게임명(가제)은 **프리즘폴 연대기 (Prismfall Chronicle)**, 약칭 "프리즘폴"로 확정하고 이후 모든 문서에서 동일하게 사용한다.
- 개발사/퍼블리셔명은 미정이며 본 문서 세트에서 다루지 않는다.
- 출시 지역은 한국/글로벌 동시 출시를 가정하며, 최초 서비스 언어는 한국어/영어/일본어/중국어 번체 4개 언어로 가정한다.
- "모바일 웹 우선"이란 앱스토어 심사 없이 URL 접속으로 즉시 플레이 가능한 WebGL 기반 게임을 의미하며, 이후 네이티브 앱 래핑(iOS/Android)은 2.0 이후 로드맵으로 별도 검토한다고 가정한다.
- 수익모델은 가챠(확률형 캐릭터/무기 뽑기) + 배틀패스 + 코스메틱 판매의 3단 구조로 가정한다.

## 1. 게임명 (가제)
**프리즘폴 연대기 (Prismfall Chronicle)**

세계의 근원인 빛 "프리마 루스"가 7개의 파편으로 흩어져 떨어진("Prism" + "Fall") 사건 이후를 배경으로 한다는 의미를 담는다. 세계관 상세는 `02_세계관기본설정.md` 참조.

## 2. 장르 포지셔닝
- **1차 장르**: 3D 오픈월드 액션 RPG
- **2차 장르(수익모델)**: 캐릭터 수집형 가챠 라이브 서비스
- **레퍼런스 포지셔닝**: "젠시인팩트 1.0 출시 시점" 수준의 스케일·비주얼 완성도를 제네릭 벤치마크로 삼되, 세계관/캐릭터/시스템 명칭은 완전히 독자적으로 설계한다. 전투의 구조적 패턴(캐릭터 스왑 파티, 원소 상호작용형 전투, 등반/활공 중심 오픈월드 탐험)은 장르 관습으로 차용하되 고유 명칭·수치·서사로 재구성한다.
- **플랫폼**: 모바일 웹(WebGL, Three.js 기반) 최우선 → PC 웹 브라우저 동시 지원 → 추후 네이티브 앱 검토(2.0+ 로드맵, 본 문서 세트 범위 밖)

## 3. 타겟 플랫폼 상세
| 항목 | 내용 |
|---|---|
| 1차 플랫폼 | 모바일 웹 브라우저 (Chrome/Safari, WebGL2) |
| 2차 플랫폼 | 데스크톱 웹 브라우저 |
| 최소 사양 목표 | 4년 이내 출시된 중급 스마트폰(예: 스냅드래곤 7세대급), RAM 6GB 이상 |
| 목표 프레임 | 모바일 30fps 고정(그래픽 옵션 '상'), 저사양 모드 24fps 허용 |
| 조작 방식 | 가상 조이스틱 + 터치 버튼 (상세는 `17_UIUX와이어프레임기획.md`) |

## 4. 핵심 판타지 (Core Fantasy)
플레이어가 플레이 중 반드시 느껴야 할 감정 3가지:

1. **"흩어진 빛의 파편을 따라, 아무도 밟지 않은 지평선 너머로 향한다"** — 새로운 지형을 발견했을 때의 경이감(오픈월드 탐험 보상).
2. **"내 손끝에서 속성들이 엮여 폭발한다"** — 공명 융합 반응을 직접 설계해 전투를 풀어내는 지적 쾌감(전투 콤보 설계감).
3. **"내가 모은 동료들이 곧 나의 이야기다"** — 가챠로 얻은 공명자 한 명 한 명에게 서사적 애착을 느끼는 수집·육성의 성취감.

## 5. 경쟁작 대비 차별점

### 차별점 1: "공명 융합 체인" — 3속성 연쇄 반응 설계
기존 장르의 2속성 즉발 반응 대신, 프리즘폴은 최대 3개 공명속성을 순서대로 연계했을 때만 발동하는 "융합 체인"을 도입한다(상세 표는 `06_전투시스템설계.md`). 이는 파티 조합의 전략적 깊이를 원소 궁합 암기에서 "실행 순서 설계"로 확장한다.

### 차별점 2: 모바일 웹 네이티브 라이브 서비스
앱 설치 없이 URL 클릭 즉시 진입 가능한 풀 3D 오픈월드를 목표로 하여, 설치 마찰 없는 바이럴 확산(링크 공유로 즉시 체험)을 차별화 포인트로 삼는다. 기술적 실현 방안은 `19_기술아키텍처계획.md`에서 상세화한다.

## 6. 프로젝트 범위 선언
- 본 문서 세트는 **1.0 런칭 스코프**(1개 메인 지역, 8~12명 캐릭터, 프롤로그+메인 챕터)를 완전히 설계하고, 향후 버전 확장은 재사용 가능한 템플릿(`20_버전업데이트로드맵템플릿.md`)으로만 정의한다.
- 모든 세계관·캐릭터·시스템 명칭은 실존 게임(원신, 붕괴3rd, 명조 등)과 겹치지 않는 완전 창작물이다.
