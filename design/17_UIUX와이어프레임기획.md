# 17. UI/UX 와이어프레임 기획 (Mobile UI/UX)

## 가정 (Assumption)
- 가상 조이스틱은 좌측 하단 고정형(플로팅 아님)으로 확정, 초심자 학습 곡선을 낮추기 위함.
- 화면 해상도 기준은 세로 모드 9:19.5(일반적 모바일 비율)로 가정.

## 1. 모바일 터치 컨트롤 레이아웃

```
┌─────────────────────────────────────────┐
│ [상단바: 체력/원기 게이지]      [미니맵]  │  ← 화면 상단 15%
│                                           │
│                                           │
│              (메인 3D 뷰)                │  ← 중앙 60%
│                                           │
│                                           │
│  [조이스틱]                [점프][회피]  │
│  (좌하단고정)          [일반공격][스킬]  │  ← 하단 25%
│                        [궁극기][스왑바]  │
└─────────────────────────────────────────┘
```

| 요소 | 위치 | 크기(참고) | 설명 |
|---|---|---|---|
| 가상 조이스틱 | 좌하단 고정 | 반경 60px | 이동 전용, 터치 시작 지점 기준 상대 이동 |
| 일반공격 버튼 | 우하단 | 70px 원형 | 연타 가능, 홀드 시 강공격 전환 |
| 스킬 버튼(공명기) | 일반공격 버튼 좌상단 인접 | 60px 원형 | 자동 재사용 게이지 표시 |
| 궁극기 버튼(각성기) | 스킬 버튼 위 | 65px 원형 | 원기 100% 시 발광 강조 |
| 회피 버튼 | 조이스틱 우측 | 55px 원형 | 스와이프 회피와 버튼 회피 동시 지원 |
| 점프/등반 버튼 | 회피 버튼 인접 | 55px 원형 | 상황별 컨텍스트 전환(점프↔등반↔활공) |
| 스왑바 | 화면 우측 세로 배치 | 캐릭터 아이콘 4개 | 탭 1회로 즉시 스왑 |
| 미니맵 | 우상단 | 화면 대비 12% | 탭하면 전체 맵 확장 |

- 엄지 도달 영역 원칙(03번 문서 5장과 연계): 모든 전투 버튼은 화면 하단 40% 내에 배치.
- 커스터마이징: 버튼 위치/크기 재배치 옵션 제공(접근성 고려).

## 2. 주요 화면 목록 및 정보 구조

| 화면명 | 상위 메뉴 | 핵심 정보 구조 |
|---|---|---|
| 홈(필드) | - | 3D 뷰 + HUD(상단 체력/미니맵, 하단 조작) |
| 캐릭터 상세 | 파티 관리 | 스탯 요약 → 스킬 트리 → 성물 장착 → 무기 장착 (탭 전환) |
| 파티 편성 | 파티 관리 | 4슬롯 드래그 배치 + 역할군 밸런스 경고 아이콘 |
| 공명 소환(가챠) | 메인 메뉴 | 배너 배너 배너(스와이프) → 확률표 링크 → 10연/1연 버튼 |
| 인벤토리 | 메인 메뉴 | 카테고리 탭(재료/성물/무기/기타) + 필터/정렬 |
| 지도 | 필드 HUD | 전체 지도 → 서브지역 확대 → 퀘스트/랜드마크 핀 |
| 퀘스트 저널 | 메인 메뉴 | 메인/서브/월드/일일 탭 구분, 진행중 항목 상단 고정 |
| 상점 | 메인 메뉴 | 아스텔 충전 / 명성 상점 / 세력 상점 탭 |
| 배틀패스(탐사 기록서) | 메인 메뉴 | 진행 트랙 시각화(가로 스크롤) + 보상 미리보기 |
| 설정 | 메인 메뉴 | 그래픽 옵션(고/중/저) / 조작 커스터마이징 / 언어 |

## 3. UX 원칙
1. **3탭 규칙**: 어떤 핵심 기능이든 홈 화면에서 3회 탭 이내 도달 가능해야 한다.
2. **즉시 피드백**: 모든 재화 획득/소모는 화면 상단에 플로팅 텍스트로 0.8초간 표시.
3. **원터치 재도전**: 던전/보스전 패배 시 "재도전" 버튼을 결과창 최상단에 배치해 로딩 최소화(19번 문서 기술 전략과 연동).
