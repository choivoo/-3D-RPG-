# 14. 가챠 시스템 설계 (Resonance Summon System)

## 가정 (Assumption)
- 확률 수치는 업계 평균(약 0.6~0.8% 급 ★5 확률대)을 참고한 오리지널 수치로, 실제 서비스 전 규제/현지법 검토가 필요하다는 전제.
- 천장(보장) 구조는 90회 기준 하드 천장 + 50%/50% 확률 시스템을 채택, 국내외 대표적 업계 관행을 일반화한 수치이며 특정 게임의 수치를 그대로 가져오지 않았다.

## 1. 가챠 명칭 및 재화
- **뽑기 명칭**: 공명 소환 (Resonance Summon)
- **무료 재화**: 루멘 조각 (Lumen Shard) — 플레이 중 각종 콘텐츠로 획득
- **유료 재화**: 아스텔 (Astel) — 현금 구매 전용, 1회 소환 = 아스텔 160 환산(참고 원화가 약 3,000원/160아스텔로 가정)
- **교환 비율**: 루멘 조각 160개 = 공명 소환 1회 (아스텔과 1:1 교환 비율로 통일하여 유저 혼동 최소화)

## 2. 배너 구조
| 배너 종류 | 설명 | 운영 주기 |
|---|---|---|
| 한정 캐릭터 배너 | ★5 특정 캐릭터 확률 업(픽업) | 약 3주 단위 로테이션 |
| 한정 무기 배너 | ★5 무기 특정 픽업 | 캐릭터 배너와 동시 운영 |
| 표준 배너(상시) | 픽업 없이 전체 상시 캐릭터/무기 균등 확률 | 상시 운영 |
| 초심자 배너 | 저확률 ★5 확정 지급 + 저렴한 가격, 계정당 1회 한정 | 신규 계정 한정 상시 |

## 3. 확률 테이블

### 3.1 캐릭터 배너 (기본 확률, 1회 소환당)
| 등급 | 확률 |
|---|---|
| ★5 | 0.7% |
| ★4 | 6.0% |
| ★3 | 93.3% |

### 3.2 등급별 세부 배분 (★4 이상 당첨 시, 05번 문서 수치와 일치)
- ★4 당첨 시 93.5% / ★5 당첨 시 6.5% — 단, 이는 ★4+★5 합산 6.7% 중 내부 비율이며 전체 확률표(3.1)가 기준.

### 3.3 천장(보장) 시스템
| 항목 | 규칙 |
|---|---|
| 하드 천장 | 90회 소환 내 ★5 미획득 시 90회차에서 100% ★5 확정 지급 |
| 확률 상승 구간(연착륙) | 75회차부터 회차당 ★5 확률 +6%p씩 선형 증가(75~89회차) |
| 픽업 배율(50/50 시스템) | ★5 획득 시 50% 확률로 배너 픽업 캐릭터, 50% 확률로 상시 풀 중 랜덤 — 픽업 실패 시 다음 ★5는 100% 픽업 확정(대천장 없음, 즉시 다음회 확정) |
| 중복 캐릭터 처리 | 중복 획득 시 "공명 각인"(제한 돌파 시스템)으로 전환, 최대 6중첩(각인 6단계) |
| ★4 소형 천장 | 10회 소환 내 ★4 이상 미획득 시 10회차 확정 지급 |

## 4. 과금 유도 최소화 밸런싱 원칙
1. **무료 재화 공급 목표**: 무과금 유저 기준 약 6~8주에 1회 공명 소환 90연차 천장 도달이 가능한 루멘 조각 공급량을 일일/주간 루프(04번 문서)에서 역산하여 설계한다(참고치: 월간 약 1,400~1,600 루멘 조각 상당 공급).
2. **천장 소멸 없음(계정 귀속)**: 배너가 교체되어도 천장 카운트는 "캐릭터 배너 계열" 전체에 걸쳐 유지되어(무기 배너와는 별도 카운트) 유저 손실감을 최소화.
3. **초심자 배너 우선 노출**: 신규 유저는 확정 ★5를 저비용으로 획득 가능하게 하여 초반 이탈률을 낮춘다.
4. **중복 캐릭터 가치 보장**: ★3~★4 캐릭터도 각인 시스템을 통해 낮은 레어도에서도 최종 전력 상한을 확보할 수 있게 하여 "뽑기 실패"의 허탈감을 완화한다.
5. **가시성 원칙**: 모든 확률 수치는 게임 내 확률 공개 화면에 전체 공개(법적 요건 충족 및 신뢰 확보).
