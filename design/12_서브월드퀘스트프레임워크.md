# 12. 서브/월드 퀘스트 프레임워크 (Sub & World Quest Framework)

## 가정 (Assumption)
- 퀘스트 보상 재화 수치는 04번 문서의 루프 시간 목표에 맞춰 역산한 임의 수치.
- 세력 호감도(팩션 포인트) 상한은 레벨당 1,000포인트로 가정.

## 1. 퀘스트 타입 분류
| 타입 | 명칭 | 반복 가능 여부 | 평균 소요시간 |
|---|---|---|---|
| 메인 퀘스트 | 연대기 퀘스트 | 불가(1회성, 스토리 진행) | 20~40분/장 |
| 서브 퀘스트 | 사연 퀘스트 | 불가(1회성, NPC별 1~3단계 체인) | 5~15분 |
| 월드 퀘스트 | 탐사 의뢰 | 불가(지역별 고정 수량, 완료 시 영구 소멸) | 3~8분 |
| 일일 위탁 임무 | 위탁 의뢰 | 가능(일일 리셋, 랜덤 4종 제시) | 2~4분 |
| 세력 임무 | 결사/청염단/교단 임무 | 가능(주간 리셋) | 5~10분 |
| 반복 파밍 던전 연계 퀘스트 | 회랑 의뢰 | 가능(일일) | 1~2분(단순 완료형) |

## 2. 보상 체계
| 퀘스트 타입 | 주 보상 | 부가 보상 |
|---|---|---|
| 메인 퀘스트 | 대량 경험치 + 스토리 전용 아이템 + 루멘 조각(가챠 재화) | 캐릭터/스킨 확정 지급(장별 1회) |
| 서브 퀘스트 | 중량 경험치 + 세력 호감도 포인트 | 소량 아스텔(유료 재화) 환산형 무료 지급 |
| 월드 퀘스트 | 탐사 점수 + 지역 성장 재화 | 코스메틱(외형) 해금 |
| 일일 위탁 임무 | 소량 경험치 + 소액 재화 | 없음 |
| 세력 임무 | 세력 호감도 포인트(대량) | 세력 전용 상점 화폐 |

## 3. 반복 가능 여부 규칙
1. 스토리 연관 퀘스트(메인/서브/월드)는 **1회 완료 후 영구 소멸**하여 서사 일관성을 유지한다.
2. 반복형 콘텐츠(일일 위탁/세력 임무/회랑 의뢰)는 **완전히 게임플레이 시스템형**으로 설계하여 서사적 모순 없이 무한 반복 가능하게 한다.
3. 예외: "재방문 전용 보상"(04번 문서 5장)은 스토리 완료 후 해금되는 반복 불가 1회성 서브 콘텐츠로 별도 취급.

## 4. 세력 호감도(팩션 포인트) 시스템
- 세력 임무 완료 시 루멘 결사/청염단/위버 교단 각각에 독립적으로 호감도 포인트 축적.
- 레벨(1~10) 구간마다 전용 보상 해금: NPC 전용 대사, 세력 상점 아이템, 세력 테마 코스메틱.
- 설계 원칙: 한 세력에 올인해도 다른 세력 메인 퀘스트 진행에 지장이 없도록(서사 강제 배타 금지, 선택은 코스메틱/부가 보상 수준에서만 차등).

## 5. 퀘스트 밀도 가이드 (세라티아 1.0 기준)
| 구분 | 수량 |
|---|---|
| 메인 퀘스트(프롤로그+5장) | 총 32개 시퀀스 |
| 서브 퀘스트(NPC 체인) | 총 24개 (NPC당 평균 3개) |
| 월드 퀘스트 | 서브지역당 6~8개, 총 약 35개 |
| 일일 위탁 임무 풀 | 총 40종 랜덤 로테이션 |
