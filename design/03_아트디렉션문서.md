# 03. 아트 디렉션 문서 (Art Direction)

## 가정 (Assumption)
- 아트 스타일은 "서브컬처 셀셰이딩" 계열로 확정(장르 벤치마크와의 비주얼 언어 정합성 및 모바일 렌더링 비용 절감을 위함).
- 캐릭터 비율/실루엣 규칙은 개발팀 내부 표준이 없다는 전제하에 본 문서에서 최초로 확정한다.
- 색상 코드(HEX)는 `02_세계관기본설정.md`의 속성 컬러와 동일한 값을 재사용한다.

## 1. 비주얼 톤 총론
- **스타일**: 반실사 비율의 서브컬처 셀셰이딩(Cel-shading) + 소프트 그라데이션 셰이더(2~3단 톤 분리, 림라이트 강조).
- **채도 전략**: 지역별 "주조색 1개 + 보조색 2개"로 제한하여 원거리 실루엣 가독성 확보(모바일 소형 화면 대응).
- **전체 채도**: 채도 60~75% 범위(과채도 지양), 명도 대비를 크게 주어 UI 대비 요소와 분리.

## 2. 캐릭터 비율 및 실루엣 규칙
| 항목 | 규칙 |
|---|---|
| 신체 비율 | 7.5등신(성인 캐릭터 기준), 소년/소녀형 캐릭터는 6.5등신까지 허용 |
| 머리 크기 | 전체 신장의 13~15% |
| 실루엣 원칙 | 각 캐릭터는 정지 포즈에서 "특징적 음영 3요소"(무기 형태, 헤어 실루엣, 망토/장식 흐름)만으로 100m 거리에서도 식별 가능해야 함 |
| 색상 규칙 | 캐릭터 1인당 고유 속성 컬러를 포인트 컬러로 최소 15% 면적에 배치(무기 발광부/눈동자/장식 문양 등) |
| 무기 크기 | 무기 타입별 표준 길이 규정: 장검 120~140cm, 쌍검 각 60~80cm, 대검 150~180cm, 활 130~150cm, 영창서 25~35cm(책 크기) |

## 3. 지역별 아트 무드보드 (텍스트 기반) — 1.0 지역: 세라티아

| 서브 지역 | 주조색 | 보조색 | 무드 키워드 | 대표 실루엣 요소 |
|---|---|---|---|---|
| 아르모나 항구 | 테라코타 오렌지 | 아이보리, 짙은 네이비 | "번잡한 무역항, 노을빛 상점가" | 삼각 돛, 목조 잔교, 걸린 등불 |
| 벨루하 숲 | 짙은 에메랄드 | 형광 연두(풍영 컬러), 갈색 | "빛이 스미는 원시림, 발광 이끼" | 뒤틀린 거목, 나선형 덩굴 다리 |
| 카르나 고원 | 황토(지맥 컬러) | 하늘색, 흰 구름 | "바람이 깎은 돌기둥 고원" | 침식된 메사(mesa) 지형, 거대 풍차형 구조물 |
| 이스나 유적 | 세피아 그레이 | 성흔 컬러(금백) | "잊혀진 위버 문명의 잔해" | 붕괴된 기둥, 부유하는 결정 파편 |
| 팔로스만 절벽 | 딥블루(수류 컬러) | 흰 포말, 회색 암벽 | "폭풍이 몰아치는 해식 절벽" | 수직 절벽, 등대, 나선 계단 |

## 4. 라이팅 & 셰이더 원칙
- 주광원: 단일 디렉셔널 라이트 + 2단 툰 램프(밝음/그림자) 셰이더, 그림자 컬러는 순수 검정 대신 보색 계열 어두운 톤 사용.
- 림라이트: 모든 캐릭터 모델에 가장자리 발광(rim light) 상시 적용, 강도는 실외 씬 0.4~0.6, 전투 씬 0.7~0.9(연출 강조).
- 파티클 예산(모바일): 화면당 동시 파티클 수 상한 300개(전투 스킬 포함), 초과 시 LOD 다운스케일.

## 5. UI 스타일 가이드 초안
| 항목 | 스타일 규칙 |
|---|---|
| 기본 폰트 | 라운드 산세리프 계열(가독성 우선), 한글은 굵은 고딕, 영문은 지오메트릭 산세리프 |
| 색 시스템 | 베이스: 다크 네이비(#1B2033) 배경 + 오프화이트(#F5F0E6) 텍스트, 강조색은 상황별 속성 컬러 차용 |
| 버튼 형태 | 모서리 반경 12px 라운드, 눌림 시 4px 다운 애니메이션(터치 피드백) |
| 아이콘 규칙 | 속성 아이콘은 다각형 크리스탈 통일 프레임 안에 배치, 등급(레어도) 테두리 색상은 `05_캐릭터시스템설계.md`의 레어도 컬러와 동일 |
| 정보 밀도 | 모바일 세로 기준 1화면 내 핵심 액션 버튼 6개 이하(엄지 도달 영역 고려, 하단 60% 영역에 배치) |

## 6. 몬스터/NPC 아트 원칙
- 몬스터는 "루멘 입자에 오염된 생물(코럽티드, Corrupted)"과 "야생 생물"로 이원화하고, 코럽티드는 반드시 균열/결정 돌기 형태의 공통 실루엣 요소를 가져 시각적으로 구분되게 한다.
- NPC 의상은 지역별 무드보드 색상 팔레트를 최우선 준수하되, 소속 팩션이 있을 경우 팩션 상징색(상세는 `10_NPC및팩션설계.md`)을 우선 적용한다.
