# 05. 캐릭터 시스템 설계 (Character System)

## 가정 (Assumption)
- 무기 타입은 5종(장검/쌍검/대검/활/영창서)으로 확정(파티 편성 다양성과 애니메이션 개발 비용의 균형점).
- 스탯 수치 범위(레벨 1/최종 기준)는 업계 평균 참고 임의 수치이며, 실제 밸런싱 단계에서 조정 대상.
- 레어도 체계는 3단계(★3~★5)로 확정, ★5가 최상위 한정 캐릭터.

## 1. 무기 타입 분류 (5종)
| 무기 타입 | 전투 스타일 | 사거리 | 표준 콤보 속도 |
|---|---|---|---|
| 장검 (長劍) | 균형형 근접, 전후 스텝 콤보 | 근접 | 중간 |
| 쌍검 (雙劍) | 고속 연타, 회피 캔슬 특화 | 근접(짧음) | 빠름 |
| 대검 (大劍) | 광역 강타, 후딜레이 큼 | 근접(넓음) | 느림 |
| 활 (弓) | 원거리 견제, 차지샷 | 원거리 | 중간 |
| 영창서 (詠唱書) | 원거리 마법형, 시전 캔슬 필요 | 중거리 | 중간(시전형) |

## 2. 공명속성별 역할군 매핑
7개 공명속성(`02_세계관기본설정.md` 참조) × 역할군을 교차 배치하여 파티 조합 다양성을 확보한다.

| 역할군 | 정의 | 주요 담당 속성(1.0 로스터 기준) |
|---|---|---|
| 딜러 (주력 딜) | 단일/광역 화력 담당, 필드 체류 시간 김 | 염광, 뇌섬 |
| 서브딜러 (스왑딜) | 짧은 스왑 진입 후 즉시 퇴장, 딜 사이클 보조 | 풍영, 뇌섬 |
| 서포터 (버프/디버프) | 파티 전체 스탯 강화 또는 적 약화 | 수류, 성흔 |
| 힐러 | 지속 회복 담당 | 수류 |
| 탱커 (보호/도발) | 실드 생성, 적 어그로 흡수 | 지맥, 성흔 |
| 유틸 (군중제어) | 동결/속박 등 CC 담당 | 빙결 |

## 3. 스탯 체계
### 3.1 기본 스탯 (전 캐릭터 공통)
| 스탯 | 약어 | 설명 |
|---|---|---|
| 체력 | HP | 생명력, 0 도달 시 전투불능 |
| 공격력 | ATK | 스킬 데미지 계산 기본값 |
| 방어력 | DEF | 피해 감소율 계산 기본값 |
| 공명력 | RES(공명력) | 스킬 피해량 배율 특수 스탯(오리지널) — 공명 융합 발동 시 추가 배율 |
| 치명타 확률 | CRIT% | 기본 5% |
| 치명타 피해 | CRIT DMG% | 기본 150% |
| 원기 회복률 | ER%(궁극기 자원 회복) | 기본 100% |
| 원소 숙련(융합 숙련도) | FM(Fusion Mastery) | 공명 융합 반응 피해량에 비례 적용 |

### 3.2 레벨별 기본 스탯 예시(★4 딜러 기준, 무보정)
| 레벨 | HP | ATK | DEF |
|---|---|---|---|
| Lv.1 | 950 | 22 | 55 |
| Lv.20 | 3,400 | 68 | 130 |
| Lv.40 | 7,200 | 128 | 240 |
| Lv.60 | 11,800 | 195 | 350 |
| Lv.80(만렙) | 16,900 | 268 | 470 |

레어도별 계수(동일 레벨 기준 배율): ★3 = 0.85배, ★4 = 1.0배(기준), ★5 = 1.35배.

## 4. 레어도 체계
| 등급 | 명칭 | 테두리 컬러 | 가챠 내 비중(참고, 상세 `14_가챠시스템설계.md`) | 특징 |
|---|---|---|---|---|
| ★3 | 정예 공명자 | 은색 (#C9D2DC) | 상시 상수(가챠 미노출, 초반 지급/상점 교환 전용) | 입문용, 4강까지 무기 슬롯 제한 |
| ★4 | 상급 공명자 | 보라 (#A970E0) | 약 93.5% (★4 이상 당첨 시) | 파티 핵심 구성원, 육성 효율 우수 |
| ★5 | 전설 공명자 | 금색 (#F2B441) | 약 6.5% (★4 이상 당첨 시) | 배너 한정/상시 최상위 전력, 고유 서사 비중 큼 |

## 5. 캐릭터 성장 슬롯 구조 (개요, 상세는 15번 문서)
- 레벨(1~80) / 돌파 단계(0~6단계, 각 단계마다 레벨 상한 해제) / 스킬 레벨(1~10) / 성물 6슬롯 / 무기 강화(1~5중첩) — 5개 축이 병렬로 전력을 구성한다.

## 6. 체크포인트 메모
1~5번 문서까지 세계관(루메브리스), 7대 공명속성, 무기 5종, 스탯 체계, 레어도(★3~★5) 명칭이 확정되었다. 이후 문서(전투/로스터/가챠)는 본 문서의 스탯·레어도 수치를 그대로 인용한다.
