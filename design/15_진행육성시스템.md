# 15. 진행/육성 시스템 (Progression System)

## 가정 (Assumption)
- 레벨 상한 80은 05번 문서 스탯표와 일치시키기 위해 고정값으로 사용.
- 성물(유물) 시스템은 6슬롯 장착형으로 확정, 세트 효과 포함.

## 1. 레벨링 커브
| 레벨 구간 | 필요 누적 경험치(참고치) | 돌파 필요 여부 |
|---|---|---|
| 1~20 | 45,000 | 불필요(초기 무료 진행) |
| 20~40 | 220,000 | 20/30/40 돌파 필요 |
| 40~60 | 680,000 | 40/50/60 돌파 필요 |
| 60~80 | 1,650,000 | 60/70/80 돌파 필요 |

- 돌파(Breakthrough) 단계: 총 6단계(Lv.20/30/40/50/60/70/80 진입마다 필요, 표는 대표 구간만 표기), 돌파 시 스탯 곡선이 계단식으로 상승하며 새 스킬 강화 슬롯 개방.
- 돌파 재료: 서브지역별 고유 몬스터 드롭 재료 + 지역 특산 재료("세라티아 정수") 조합.

## 2. 장비 체계

### 2.1 무기
| 항목 | 규칙 |
|---|---|
| 무기 레벨 상한 | 90 (캐릭터보다 10 높게 설계해 상한 여유 제공) |
| 무기 강화 중첩(정련) | 1~5단계, 단계마다 무기 고유 특수효과 수치 강화 |
| 무기 등급 | ★3~★5 (05번 캐릭터 레어도 체계와 동일 등급 체계 사용) |

### 2.2 성물 (유물, Resonance Relic)
| 슬롯 | 명칭 | 주 옵션 예시 |
|---|---|---|
| 1 | 심핵(코어) | HP% / ATK% / DEF% |
| 2 | 촉매 | 공명력(RES) 고정치 |
| 3 | 인장 | 치명타 확률/피해 |
| 4 | 매개체 | 특정 속성 피해량% |
| 5 | 결속구 | 원기 회복률% |
| 6 | 문장 | 융합 숙련(FM) 고정치 |

- 세트 효과: 2세트(2개 장착 시 소형 효과) + 4세트(4개 장착 시 강력 효과, 특정 공명속성/역할군 특화) 구조.
- 성물 강화 레벨: 0~20강, 4강마다 부옵션 1개 추가 부여(최대 4개 부옵션).

## 3. 재료 파밍 루프
- 요일별 파밍 던전 지정: 메아리 회랑(09번 문서)이 요일마다 상이한 돌파 재료 세트를 드롭하도록 로테이션 → 일일 루프(04번 문서)와 직결.
- 세력 임무(12번 문서) 보상으로도 일부 공용 재료(정련석 등) 획득 가능 → 스토리/육성 루프 연결.

## 4. 파워 상승 곡선 (참고 그래프 - 텍스트 표현)
| 전력 구간 | 대응 콘텐츠 |
|---|---|
| 초반(Lv.1~20, 돌파0~2) | 프롤로그~1장, 메아리 회랑 난이도 1 |
| 중반(Lv.20~50, 돌파2~4) | 2~4장, 심연 회랑 개방 |
| 후반(Lv.50~80, 돌파4~6) | 5장 및 주간 보스(코어 수호자) 공략 |
| 엔드콘텐츠(만렙+성물 20강) | 심연 회랑 고난이도, 랭킹 콘텐츠 |

- 설계 원칙: 무과금 유저도 만렙+성물 12강 수준까지는 무리 없이 도달 가능하도록 재료 공급량을 설계하고, 20강 최종 구간부터 파밍 시간 투자가 유의미하게 벌어지도록 한다(장시간 F2P 유저와 과금 유저 격차를 "속도" 차이로 한정, "가능/불가능" 차이로 만들지 않음 — 16번 경제 문서와 연동 원칙).
